# dotfiles

Various personal dotfiles managed with [chezmoi](https://www.chezmoi.io/). Primarily focused on [Neovim](https://neovim.io/)
and [Homebrew](https://brew.sh/), with some other configs mixed in there and a big focus on
[Catppuccin](https://catppuccin.com/) theming.

## Disclosure

Dotfiles are both handwritten and AI-assisted. Absolutely zero stability
guarantees beyond the fact they (probably) work on my machines.
